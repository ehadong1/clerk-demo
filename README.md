# 클러크 팀 시연

예시 자료를 이용해 경리 업무 흐름을 체험하는 시제품입니다.

시연 주소: https://ehadong1.github.io/clerk-demo/

실제 Gmail·회계 시스템과는 연결되지 않으며, 실제 회사 자료나 인증정보를 포함하지 않습니다. 앱에 입력한 자료는 현재 브라우저에만 저장됩니다. 이 저장소의 HTML·CSS·JavaScript 파일은 공개됩니다. 실제 회사 업무를 운영하는 서비스가 아닌 팀의 기능 검토용 화면입니다.

## 체험 순서

1. AI 직원 메일함에서 4건 일괄 처리를 실행합니다.
2. 업무 보드에서 자동 등록된 업무를 확인합니다.
3. 검토와 승인에서 예시 거래를 승인해 집계 변화를 확인합니다.
4. 실제 이메일 발송과 지급은 실행되지 않습니다.

개발용 전체 소스와 검사 코드는 소유자가 별도로 관리하는 비공개 저장소에 있습니다.
