# 클러크 팀 시연

예시 자료로 경리 업무 흐름을 체험하는 시제품입니다.

- [시연 앱](https://ehadong1.github.io/clerk-demo/)
- [사용 가이드와 따라 하기](https://ehadong1.github.io/clerk-demo/#tutorial)

## 대시보드에서 시작하는 체험

1. 사용 가이드에서 월간 지출, 검토 대기, 누락 증빙, 업무 진행률이 무엇인지 확인합니다.
2. 대시보드의 **지출 보고서**를 요청하고 결과와 CSV를 받습니다.
3. **비용 검토 요청**에서 거래처·금액·담당자·기한을 입력합니다. 거래 초안과 증빙 확인 업무가 함께 생기고, 아래 처리 결과에서 확인할 수 있습니다.
4. **증빙 누락 점검**으로 원본이 필요한 거래를 찾습니다. 자료함에서 파일을 올리고 거래와 연결한 뒤 검토합니다.
5. **검토와 승인**에서 네이버클라우드 예시 거래를 열어 앱 내 승인을 기록합니다.
6. 업무 보드·자료함·AI 도우미·회의 지원·메일함의 사용 방법은 가이드의 각 화면 열기에서 이어집니다.

상단의 **사용 가이드**에서 언제든 다시 시작할 수 있습니다. 가이드를 실행해도 기존 입력 자료는 유지됩니다.

## 시연 범위

실제 Gmail·회계 시스템과 연결되지 않으며 실제 이메일 전송, 지급, 세무 확정, ERP 반영은 수행하지 않습니다. 실제 회사 자료나 인증정보는 포함하지 않습니다.

입력 자료는 현재 브라우저에만 저장되어 다른 팀원과 공유되지 않습니다. 실제 회사 자료 대신 예시 자료로 체험해 주세요. 이 저장소의 HTML·CSS·JavaScript는 공개됩니다. 개발용 전체 소스와 검사 코드는 소유자의 비공개 저장소에서 관리합니다.
